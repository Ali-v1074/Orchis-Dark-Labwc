# Orchis-Dark-Labwc

A **labwc theme inspired by Orchis Dark**.

## Installation

Move `Orchis-Dark-Labwc` to `~/.themes`.

Enable it from `rc.xml` or [**Labwc Tweaks**](https://github.com/labwc/labwc-tweaks).

Remove `themerc-override` from `~/.config/labwc`.
